# Llegadas al almacén

Página para que los proveedores registren su carga y compartan su ubicación hacia el patio de recepción.

- `index.html`: página del proveedor (la abre el QR)
- `panel.html`: panel del almacén (requiere clave)
- `config.js`: URL de la API de Google Apps Script

Los datos se guardan en Google Sheets; este repositorio no contiene claves ni datos.
